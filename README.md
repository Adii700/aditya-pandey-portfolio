Aditya Pandey Portfolio

This package includes Google Analytics 4 tracking for Measurement ID G-MQ2WVX7E8C.

Files:
- index.html: main portfolio with page-view tracking, section-view events, resume link events, Study Materials link events, and chatbot interaction events.

To publish: upload/replace these four files at the root of the GitHub Pages repository and commit the changes. After deployment, open the live site and check Google Analytics > Reports > Realtime. Data may take some time to appear.
