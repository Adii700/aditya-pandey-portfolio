# Aditya Pandey — QA Engineer Portfolio

## Open directly
1. Extract this ZIP.
2. Open `index.html` in Chrome or another modern browser.
3. The portfolio works offline; an internet connection is only needed for external LinkedIn/GitHub links.

If your Android file manager does not offer Chrome/browser when you tap `index.html`, use **Open with → Chrome**. Some Android file managers do not support launching local HTML files directly.

## Files
- `index.html` — complete portfolio website
- `resume.pdf` — resume download used by the portfolio
